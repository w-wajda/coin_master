# PLAN DZIAŁANIA - Aplikacja Coin Master (Zarządzanie Paragonami)

## 🎯 Cel Projektu
Aplikacja do zarządzania paragonami z analizą wydatków, śledzeniem cen produktów i zarządzaniem gwarancjami.

---

## 📊 CURRENT STATE BACKENDU

### ✅ Co już istnieje:
- FastAPI + SQLAlchemy 2.0 + asyncpg
- Clean Architecture (domain, application, infrastructure, presentation)
- User, Company, Receipt, Item entities
- Docker setup (PostgreSQL, Redis, MinIO)
- Pydantic validations
- S3-compatible storage (Boto3/MinIO)
- Email integration (fastapi-mail)
- Pre-commit hooks, testing setup

### Tech Stack:
- Python 3.12.7
- FastAPI 0.115.4
- SQLAlchemy 2.0.36
- PostgreSQL + asyncpg
- Redis (caching, message broker)
- MinIO/S3 (photo storage)
- Pillow (image processing)
- PyTest + Factory Boy (testing)
- Sentry (error monitoring)
- Line length: 120 chars (Black, isort)

## ⚠️ BRAKUJĄCE ELEMENTY NA MVP

### Receipt model - brakuje:
- date_purchase: datetime (kiedy kupiono)
- notes: Optional[str] (uwagi o garantii, itp.)
- created_at, updated_at timestamps

### Item model - brakuje:
- quantity: Decimal (ilość produktu)
- unit: str (szt, kg, litr, etc.)
- unit_price: Decimal (cena za jednostkę)
- category: str (spożywcze, ubraniowe, etc.)
- tags: relacja do tagsów

### Nowe entities potrzebne:
1. **Category** - kategorie produktów (hierarchiczna struktura)
2. **Tag** - tagi do paragońskiego, produktów
3. **Warranty** - informacje o gwarancji (data_wygaśnięcia, produkt, notificatin_email)
4. **Receipt_History** - historia cen produktów
5. **UserPreferences** - ustawienia użytkownika

### Company model - brakuje:
- address: str
- city: str
- phone: Optional[str]
- website: Optional[str]
- store_type: str (supermarket, sklep odzieżowy, etc.)

## 🎁 MVP SCOPE

### Phase 1: Upload & Manual Entry
- [ ] Zdjęcie paragonu (S3 upload)
- [ ] Uzupełnienie danych paragraonu (data, sklep, kwota)
- [ ] Dodawanie produktów z kategorią i ilością
- [ ] Wylistowanie moich paragonów
- [ ] Edycja/usuwanie paragraonu i produktów

### Phase 2: OCR (optional, graceful degradation)
- [ ] Wczytanie zdjęcia
- [ ] Próba ekstrakcji tekstu z OCR
- [ ] Jeśli OCR ma problemy → wypełnianie ręczne
- [ ] Zaproponowanie kategorii na podstawie nazwy produktu

### Phase 3: Analytics & Insights
- [ ] Wydatki: dzień, tydzień, miesiąc, rok
- [ ] Wydatki wg kategorii
- [ ] Średnia wartość paragraonu

- [ ] Historia cen produktu (trend)

### Phase 4: Warranty Management
- [ ] Dodawanie info o gwarancji do produktu
- [ ] Email reminder przed wygaśnięciem gwarancji
- [ ] Lista aktywnych gwarancji

### Phase 5: Mobile (React Native)
- [ ] Ekran kamery (upload zdjęcia)
- [ ] Ekran edycji paragraonu
- [ ] Lista paragonów
- [ ] Analytics dashboard
- [ ] Ustawienia
